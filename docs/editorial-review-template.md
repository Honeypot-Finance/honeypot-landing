## Review, after drafting

Use pass / revise / pending with specific evidence, not just checkmarks. Identify a reviewer or accurately mark a self-review; an automated check is not an independent editorial review.

| Criterion | Status and evidence |
| --- | --- |
| Opening promises a question the body actually answers | Cite the opening and the section that delivers. |
| Each section advances a distinct step in the argument | Name a repeated setup removed, or explain the progression. |
| Factual claims match current primary sources | Map the main claims to sources; distinguish facts, interpretation, proposals, and examples. |
| Voice is specific and natural | Quote a passage checked or revised; identify borrowed experience, filler, or formulaic writing removed. |
| Ending answers the opening and develops an earned consequence | Cite the ending and the evidence supporting its larger implication. |
| Ending passes the cross-article swap check | Name a neighboring article and explain why this conclusion belongs here. |
| Cover and inline animation explain this article | Record the scene, placement, conceptual boundaries, and mobile/reduced-motion checks. |
| Florus attribution and useful card summary remain | Record where checked. |
| Routes, category, references, related links, and build | Record actual checks, results, and any skipped checks. |
